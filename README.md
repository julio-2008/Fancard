# ⚽ FanCard Brasil | Colecionáveis de Copa do Mundo Personalizados

Transforme fotos comuns em figurinhas físicas exclusivas inspiradas no álbum oficial da Copa do Mundo. Um sistema completo projetado para engajar clientes apaixonados por futebol através de uma experiência hyper-premium e automatizada.

---

## 💎 A Experiência de Valor (Como Funciona)

### 1. Seleção do Pacote & Atributos
* O cliente define a quantidade desejada de pacotes físicos.
* Preenche os dados táticos que serão exibidos no card (Nome, Posição, Seleção de preferência e atributos numéricos como Velocidade, Passe e Chute).
* Faz o upload da foto pessoal com verificação instantânea no navegador.

### 2. Layout Cinema & Edição Manual
* **Diferencial Competitivo:** Diferente de geradores automáticos borrados, a FanCard utiliza tratamento profissional.
* Nossa equipe de designers gráficos realiza o recorte limpo do fundo da imagem contratada, aplica correção de iluminação de estúdio e equilibra as cores para a integração perfeita dentro do template oficial.

### 3. Pagamento Integrado
* Checkout instantâneo e seguro via **Mercado Pago Checkout Pro (Pix, Cartão de Crédito e Boleto)** com atualização em tempo real de transação.

## 🛠️ Arquitetura Tecnológica

* **Frontend:** React 19 executado via Vite com animações suaves de transição de status construídas em Framer Motion.
* **Backend:** Express API rodando em ambiente Node integrado com SDK oficial do Mercado Pago para verificação robusta de Webhooks.
* **Banco de Dados:** Estrutura local persistente para acompanhamento de produção em tempo real por meio de hashes seguros criptografados.
